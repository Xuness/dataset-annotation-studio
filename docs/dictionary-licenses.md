开始直接下载前，界面会显示：

- 来源仓库与固定版本；
- 许可证标识、原始条款入口和来源风险说明；
- 词典内容不属于 Dataset Annotation Studio 的提示。

确认记录只用于证明本次下载由本机用户主动发起，不代表项目作者对第三方授权范围作出
法律保证。删除下载记录或词典安装不会删除全局修正词条。

## 角色审查语义词表

角色审查使用独立的语义索引，不把角色名单、标签分类和关联关系混入翻译词典。
通过新主题的“标注生产 → 角色标签审查”主动导入一个包含以下文件的目录：
`danbooru_character_tags.csv`、`danbooru_dataset_general.csv`、
`danbooru_tag_near_synonyms.csv`。

参考来源为 `storyAura/BooruDatasetTagManagerPlus` 的
`682a842fdab63baacda5f0b3f3727f379f3b66ed` 版本。其程序仓库声明 MIT，
词条涉及 Danbooru 等来源，授权状态显示为混合来源；导入不改变内容的上游授权。
应用要求用户填写来源版本并明确确认，既不自动下载，也不把词表提交到源码。
代码的参考署名和上游许可保存在角色审查模块的 `UPSTREAM_LICENSE` 中。

安装位于当前词典根目录下的 `character-audits/<fingerprint>/`，保存原始 CSV、
来源确认清单和只读 SQLite 语义索引。指纹绑定来源版本及三个原文件的 SHA-256，
执行前校验索引完整性；缺少资源、格式错误或校验失败会阻止审查，不降级为空词表。
角色和通用词条保留各自类别，允许同一词同时出现在两个来源类别中。
关联图仅标识可能描述同一部位的候选，不授权自动同义替换。
