# Legacy 非破坏性裁剪工作台嘎呜

## 目标与范围嘎呜

现有「图像预处理｜单图精细裁剪｜批量裁剪」顶栏保持设计、顺序与名称，图像预处理内容不改，只改 Legacy 两个裁剪页面，V2 不维护嘎呜

两个工具采用左侧素材栏、右侧页内工作区，共用「单图操作／总览」视图；历史记录位于右侧可展开区域，不是第三个常驻主栏嘎呜

## 导航、工作集与草稿嘎呜

- 单图路由为预处理页 `tool=crop-single`，批量为 `tool=crop`，顶栏仅切换工具内容与选中态嘎呜
- 素材页精细裁剪入口通过 `asset` 参数定位原图，移除裁剪浮窗与关闭返回素材页的流程，生成结束也停留工作台嘎呜
- 顶栏进入单图使用素材页勾选集合；指定图已在勾选集合内则保留集合，否则只处理该图，不改变素材页勾选状态嘎呜
- 批量默认使用勾选集合，同时支持当前筛选、指定子目录、当前有效范围全部素材，遵守候选集边界并排除已生成裁剪结果，空勾选不解释为全部嘎呜
- 草稿按项目、模式、源图保存于会话状态，切图、切视图、切工具及暂时离开页面不丢失，不跨重启恢复，退出应用提醒未生成编辑嘎呜
- 素材列表每页 50 张，总览每页 24 张源图；总览按源图分组显示全部区域，未配置图也保留可点击入口嘎呜

## 编辑与生成规则嘎呜

- 单图每张原图允许多个重叠裁剪框，每框独立自由或固定比例，支持移动缩放、精确坐标、画布缩放与自由拖动嘎呜
- 画布直接左键框选，不提供冗余的框选开关、缩放滑条或实际像素按钮；滚轮以鼠标位置为中心缩放，空格＋左键向任意方向自由拖动整张图片，不受滚动条边界限制，Shift／中键不再平移嘎呜
- 保留适应窗口操作，同时复位缩放与图片位移；画布变换不改变裁剪原生像素坐标，单图与批量共用一致手势嘎呜
- 删除按钮每次移除区域列表最上面的框，无需选择，选中其他框也按列表顺序删除，保留剩余框身份、生成状态和参数嘎呜
- 左侧素材列表、中间工作区、右侧参数栏各自独立滚动，到边界不带动其他栏；画布上的滚轮仅缩放，中间区域其余位置正常上下滚动嘎呜
- 批量每张原图一个满足统一比例的最大矩形，初始居中，点击素材或总览卡片直接在右区拖动位置；尺寸固定，可恢复居中，不加入缩小框、多框或逐图比例嘎呜
- 更改统一比例存在手调位置时须确认重置；取消保持原比例、位置与草稿嘎呜
- 单图操作生成当前图的待处理区域，总览支持一次生成所有图片已配置且待处理区域；两视图都保留当前／全部生成入口，未配置明确计数但不生成嘎呜
- 执行前重新生成并验证后端计划，明确显示源图数与输出数，再确认执行；界面预览随草稿更新，不重用修改前的执行计划嘎呜
- 成功后保留区域，未修改已生成项不重复执行；新增或修改重新待生成，显式重新生成创建新文件而不覆盖旧结果嘎呜
- 状态区分未配置、待生成、已生成、失败，单项出错或非法坐标明确阻止相关提交嘎呜

## 数据与安全边界嘎呜

- 多源区域请求和带位置批量请求各创建一份不可变计划、一笔操作，一次提交所有目标，不循环单图执行来伪装事务嘎呜
- 批量后端检查统一比例、最大固定尺寸、源图版本、坐标边界、候选范围以及不得包含裁剪生成素材嘎呜
- 旧 single／batch 计划和历史记录仍可读取，新请求使用独立持久化类型，不改已有迁移嘎呜
- 原图、原身份、原标注和旁车字节不变，输出为独立 PNG，位于 `cropped/`，按源相对路径分目录、序号命名，新图不继承标注嘎呜
- EXIF 转正坐标、透明与色彩信息、解码支持边界沿用既有裁剪模块，不能支持的静态模式或多帧输入明确拒绝嘎呜
- 复用既有互斥、staging、发布、进度、整批回滚、崩溃恢复、来源追溯和撤销保护，失败不遗留被视作成功的半批资产嘎呜
- 撤销只移除本笔操作的结果，后续依赖、标注、文件修改或操作顺序冲突明确阻止嘎呜
